# Online Kütüphane Yönetim Sistemi

Bu proje, kullanıcıların kitapları listeleyebildiği, kategorilere göre filtreleme yapabildiği ve kitapların detaylarını inceleyebildiği modern bir kütüphane otomasyon uygulamasıdır.

## Proje Hakkında
- **Kısa Açıklama:** Kullanıcıların kütüphane envanterine erişmesini, kitap durumlarını kontrol etmesini ve dijital içerikleri görüntülemesini sağlayan Flutter tabanlı mobil uygulama.
- **Öne Çıkan Özellikler:** Kitap arama, kategori filtreleme, ödünç alınan kitapların takibi ve kitap okuma modu.

## Kullanılan Teknolojiler ve Sürümler
- **Flutter:** 3.24.5
- **Dart:** 3.5.4
- **Paketler:** `intl`, `cupertino_icons`

## Çalıştırma Adımları

Projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

1. **Repoyu Klonlayın:**
   ```bash
   git clone <repository-url>
   ```

2. **Bağımlılıkları Yükleyin:**
   Proje ana dizininde terminale şu komutu yazın:
   ```bash
   flutter pub get
   ```

3. **Uygulamayı Çalıştırın:**
   Bir emülatör veya gerçek cihaz bağlıyken:
   ```bash
   flutter run
   ```
